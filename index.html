About & privacy

TeeDraw stores your players, draws and scores only on this phone. Saved rounds (History) are kept the same way, in your browser’s storage on this phone: nothing is uploaded, and you choose when to export a backup file or share a round. If anonymous usage stats are switched on, we count things like "a draw was made with 12 players in 3 groups" or "a round was finished at Monzi", plus a rough country/region worked out from the connection. Live events (optional): if you create or join an event and live sharing is set up, that event’s first names/nicknames, course handicaps, tee times and scores are stored online so people with the event link or QR can watch. Event codes are random (about 100 bits), never listed, and only people with the separate scorer link can change scores. Use first names or nicknames only – no surnames or phone numbers. Without live setup, events stay on this phone. We never send player names, phone numbers, scores per person or anything that identifies you, and we use no cookies and no tracking across other sites. This helps us show sponsors how many golfers use the app. Community courses: if you add a course from a scorecard photo and leave “Share with everyone” ticked, the course name, town, pars, stroke index, optional tee ratings, the photo and (only if you tick it) the course’s location are stored online and shown to all TeeDraw users; a random key kept on your phone lets only you correct your own entry. Photograph only the printed card, not people. “Find nearby course” reads your position once to compare it with saved courses on your phone; it is never stored or sent. Sharing: a player-list link carries the names and handicaps inside the link itself (nothing is stored online). A club code (optional) stores the club name and a list of first names with handicaps online, readable by anyone who has the random code and changeable only with the organiser’s key. A shared round’s course, draw, handicaps and team settings are stored with the live event, and scorers use a separate scorer key that can write scores but cannot change the setup. Suggestions: if you send one, the text, the optional name/contact you typed, a category, the app version and a random device code (to limit spam) are stored and read by the TeeDraw team – don’t include personal info. Questions: contact the TeeDraw team.
